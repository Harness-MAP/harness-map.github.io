Harness-MAP

Budget-Efficient Harness Search via Structure-Token Factorization

Mei Yuan· Yingshan Chang· Daniel Fried· Yonatan Bisk

Carnegie Mellon University

Preprint · 2026

Paper (PDF) Code Evolution packs BibTeX

The idea

The question

How can we efficiently search for a diverse set of high-quality harnesses under a tight evaluation budget?

Automating harness evolution via naive meta-agent search is prohibitively expensive: a full search loop may require hundreds of meta-agent calls, and a single candidate evaluation can take minutes to hours. A core issue in prior work is the unstructured space, where a harness has no coordinates, so a search step has no size and a search trajectory has no coverage.

The idea

Structure the search space by factorizing graph-level program structures from token-level implementations.

Bilevel search over this structure–token representation space illuminates an archive of diverse, high-quality harnesses. The map also enables a resolution-adaptive search strategy: partitions with high fitness variance are sub-split, and ineffective refinements are retracted, so evaluation budget concentrates where deeper search yields performance gains.

Every number on this page comes from the same frozen Qwen3-VL-30B-A3B-Instruct; only the harness around it changes.

Abstract

Automating harness evolution via naive meta-agent search is prohibitively expensive, requiring hundreds of meta-agent calls and minutes-to-hours per evaluation. How can we efficiently search for a diverse set of high-quality harnesses under a tight evaluation budget? To address this, we introduce Harness-MAP to structure the search space, factorizing graph-level program structures from token-level implementations. Bilevel search over this structure-token representation space illuminates an archive of diverse, high-quality harnesses. The map also enables a resolution-adaptive search strategy that navigates this space efficiently, sub-splitting partitions with high fitness variance while retracting ineffective refinements. Across three interactive spatial navigation benchmarks with the frozen Qwen3-VL-30B-A3B-Instruct backbone model, our search approach rapidly achieves performance leaps under minimal evaluation budgets: 10.7% → 100.0% on SpatialWorld-3dgames (39 evals), 10.0% → 90.0% on BALROG-MiniHack (41 evals), and 32.5% → 46.5% on SimWorld-Robotics (6 evals). Harness-MAP outperforms prior harness evolution methods across both search and held-out tasks, establishing factorized representations as an effective Quality-Diversity paradigm for budget-aware agent harness search.

Method

A factorized map, searched at adaptive resolution.

Harness-MAP structures harness candidates into a factorized representation space and searches across two levels: high-level steps refine the structural skeleton shared across a family of harnesses, while low-level steps flesh out that skeleton with token-level implementations.

Given a frozen foundation model \(M\) and a task distribution \(\mathcal X\), a harness \(H \in \mathcal H\) is the executable program that turns \(M\) into a functional agent. Executing \(H\) on \(x \sim \mathcal X\) yields a trajectory \(\tau \sim p_M(H, x)\) scored by reward \(r(\tau, x)\). Harness search seeks the optimal harness program:

\[ H^\star = \arg\max_{H \in \mathcal H}\ \mathbb E_{x \sim \mathcal X,\ \tau \sim p_M(H, x)}\big[\, r(\tau, x) \,\big] \tag{1} \]

Existing harness evolution paradigms conduct search directly over the raw, token-level space of possible harnesses, relying on an LLM proposer to iteratively edit low-level programs. Since this unstructured token space lacks coordinate metrics, these methods search blindly, without insight into unexplored regions or search coverage. Harness-MAP instead restructures \(\mathcal H\) into a map of cell partitions \(\mathcal C\). During search, the framework maintains an archive \(\mathcal A = \{H_c\}_{c \in \mathcal C}\) storing the elite candidate \(H_c\) with best-so-far performance for each cell \(c\):

\[ H_c = \arg\max_{H \in c}\ \mathbb E_{x \sim \mathcal X,\ \tau \sim p_M(H, x)}\big[\, r(\tau, x) \,\big] \tag{2} \]

Occupied cells provide an explicit view of search coverage and fitness distribution, and mapping candidates to this coordinate space makes search step sizes measurable along visible trajectories: intra-cell movement for minor edits, inter-cell movement for major structural shifts.

Adapting map resolution
Harness-MAP construction

Factorizing a harness

§3.2

Built on CVT-MAP-Elites, Harness-MAP constructs its representation space by factorizing each harness into a structural skeleton and a token-level implementation, \(H = (s, \theta)\). The joint descriptor

\[ \phi(H) = \big(\phi_S(s);\ \phi_T(\theta)\big) \in \mathbb R^{d_S} \times \mathbb R^{d_T} \tag{3} \]

allows structural and token moves to be measured independently.

Structural descriptor \(\phi_S(s)\)

The skeleton of \(s\) is its top-level architectural wiring, encoded as a directed graph \(G(s) = (V, E)\): vertices are top-level components (functions, classes, modules) and edges are call, reference or import dependencies extracted by AST parsing. Vertices receive initial functional role labels \(\ell_0(v)\) (e.g., perception, policy, controller). \(L\) rounds of Weisfeiler–Lehman refinement capture role-aware multi-hop topology, \[ \ell_{t+1}(v) = \mathrm{hash}\big(\ell_t(v),\ \{\!\{\ell_t(u) : u \in N(v)\}\!\}\big), \tag{4} \] and \(\phi_S(s)\) is the normalized histogram over the codebase-wide pattern space \(\Lambda = \bigcup_{t \le L} \Lambda_t\): \[ \phi_S(s) = \Big[\, \tfrac{\#_t(\lambda)}{|V|} \,\Big]_{t \le L,\ \lambda \in \Lambda_t}. \tag{5} \] Each dimension is a specific \(t\)-hop component-connectivity pattern; its value is the proportion of components exhibiting it.

Token-level descriptor \(\phi_T(\theta)\)

Three feature blocks capture the internal implementation logic: AST control-flow statistics \(f_{\mathrm{AST}}\), numeric constant parameters \(f_{\mathrm{num}}\) and documentation embeddings \(f_{\mathrm{doc}}\). Each block is z-score standardized and rescaled by its dimension, \[ \phi_T(\theta) = \Big[\, \sqrt{\alpha_1}\tfrac{\hat f_{\mathrm{AST}}}{\sqrt{d_{\mathrm{AST}}}};\ \sqrt{\alpha_2}\tfrac{\hat f_{\mathrm{num}}}{\sqrt{d_{\mathrm{num}}}};\ \sqrt{\alpha_3}\tfrac{\hat f_{\mathrm{doc}}}{\sqrt{d_{\mathrm{doc}}}} \,\Big], \tag{6} \] with \(\alpha_1 = \alpha_2 = \alpha_3 = 1\), so that no block dominates the distance metric and \(\phi_T\) is invariant to codebase size.

Partitioning into cells

To prevent sparse partitions in high dimensions, the space is partitioned with a Centroidal Voronoi Tessellation: fitting \(k\) centroids \(Z = \{z_1, \dots, z_k\}\) by k-means over sampled descriptors defines each cell \[ C_i = \big\{ H \in \mathcal H : \|\phi(H) - z_i\| \le \|\phi(H) - z_j\|\ \ \forall j \big\}, \tag{7} \] so a candidate is assigned by nearest-centroid lookup. Fitting centroids relies on static descriptors and consumes zero evaluation budget; the resolution parameter \(k\) is optimized dynamically during search.

Searching over the Harness-MAP

Quality-diversity archiving with LLM-guided variation

§3.3, Algorithm 1

Standard CVT-MAP-Elites maintains quality-diversity in a coordinate space but lacks semantic guidance; typical harness evolution methods operate over an unstructured loop (propose → evaluate → diagnose → refine) driven by LLM feedback and, lacking structured spatial coverage, waste expensive rollouts on candidates that yield marginal gains or homogeneous behaviors. Harness-MAP (Algorithm 1b) unifies QD archiving with LLM-guided evolutionary search. Steps marked meta-agent call the language model; steps marked map read only the archive.

  1. 0Coverage initialization

    The meta-agent proposes candidate root harnesses to populate the base cells. Each proposal undergoes a post-verifier of validity filtering before evaluation. Sampling continues until occupied cells satisfy a target coverage percentage of the initial \(k_0\) cells (\(m\%\,k_0\)).

  2. 1Batched selection

    \(H_{\mathrm{batch}} \leftarrow \mathrm{selection}(\mathcal H, B)\): elites are selected across the map rather than along a single lineage.

  3. 2Diagnosis

    \(\mathrm{diag} \leftarrow \texttt{meta\_agent.diagnosis}(H, \mathcal H)\): an accumulated diagnosis of the parent's local failure modes.

  4. 3Directive-steered variation

    For each of the \(b\) children, a component-aware directive translates target coordinates into explicit structural or token-level refinements, and \(H' = \texttt{meta\_agent.variation}(H, \mathrm{diag}, \mathrm{directive}_j)\).

  5. 4Validity filter

    \(\texttt{is\_valid}(H')\): invalid harnesses are filtered before any rollout is spent.

  6. 5Add to archive

    The child is evaluated, assigned to its nearest-centroid cell and kept if it improves on the cell's elite.

  7. 6Adapt resolution

    \(\texttt{ADAPT\_RESOLUTION}(\mathcal H, P, C)\): the dynamic sub-split of §3.4, at zero evaluation cost.

Feedback-conditioned code mutations often suffer from unguided behavior drift. Conditioning candidate generation jointly on the parent harness, the accumulated diagnosis and a component-aware directive (e.g., more or fewer perception components for structural edits, similar implementations of a specific module for token-level mutations) steers evolution toward targeted map cells, concentrating compute on functional candidates that fill distinct behavioral cells.
Adapting map resolution

Sub-splitting as a localized, data-driven hypothesis

§3.4, Algorithm 2

Standard MAP-Elites uses static search granularity, which wastes evaluations on uniform cells while ignoring distinct candidates in high-variance ones. At each search step \(t\), Harness-MAP adapts cell resolution at zero evaluation cost. Sub-splitting. The single occupied cell with the largest internal fitness range is divided via local clustering CVT; the other cells remain unchanged, avoiding partitioning on flat and saturated task landscapes. Reversion and memory. A sub-split is retained only if the child cells outperform the original parent elite; otherwise the subdivision is reversed, and the parent cell logs a memory of its fitness distribution, avoiding redundant re-splitting until a novel candidate alters it.

Results

Budget-matched.
Every benchmark.

Every method starts from the same reference harness and the same frozen policy model and receives the same candidate-evaluation budget: N = 50 on SpatialWorld-3DGames and BALROG-MiniHack, N = 16 on SimWorld-MMNav.

Harness-MAP establishes a new state-of-the-art across all three benchmarks under budget-matched evaluation, outperforming both direct inference with frontier models and prior harness search methods.

Sample efficiency in evaluations and in sequential steps

Harness-MAP achieves high sample efficiency across both evaluation budgets and search steps: it reaches peak performance within fewer search steps, coverage-gated initialization frequently discovers optimal harnesses before the main loop (e.g., Snake, Maze), and adaptive resolution refines the map incrementally rather than exponentially.

Resolution dynamics

archive cells vs. step T

Dynamic resolution mitigates sensitivity to the initial cell count \(k_0\) by preventing archive over-partitioning: fixed resolution stays static, hierarchical expansion grows the archive regardless of what the search finds, and adaptive resolution sub-splits where fitness varies and retreats where a split did not pay.
