Abstract

Automating harness evolution via naive meta-agent search is prohibitively expensive, requiring hundreds of meta-agent calls and minutes-to-hours per evaluation. How can we efficiently search for a diverse set of high-quality harnesses under a tight evaluation budget?

To address this, we introduce Harness-MAP to structure the search space, factorizing graph-level program structures from token-level implementations. Bilevel search over this structure-token representation space illuminates an archive of diverse, high-quality harnesses. The map also enables a resolution-adaptive search strategy that navigates this space efficiently, sub-splitting partitions with high fitness variance while retracting ineffective refinements. Across three interactive spatial navigation benchmarks with the frozen Qwen3-VL-30B-A3B-Instruct backbone model, our search approach rapidly achieves performance leaps under minimal evaluation budgets: 10.7% → 100.0% on SpatialWorld-3DGames (39 evals), 10.0% → 90.0% on BALROG-MiniHack (41 evals), and 32.5% → 46.5% on SimWorld-Robotics (6 evals). Harness-MAP outperforms prior harness evolution methods across both search and held-out tasks, establishing factorized representations as an effective Quality-Diversity paradigm for budget-aware agent harness search.

Method

A map instead of a lineage

What turns a frozen model into an agent is its harness: the prompts it reads, the tools it may call, the memory it keeps, and the control flow that connects them. Letting an LLM meta-agent rewrite the harness from execution feedback works, but a naive loop is expensive. A single candidate evaluation takes 7.8 minutes on 40 episodes of BALROG-MiniHack and 10.7 hours on 50 episodes of SimWorld-Robotics-Hard, and in a space with no coordinates a search step has no size and a trajectory has no coverage. Harness-MAP gives every harness coordinates, keeps an archive of elites across the resulting map, and spends its evaluation budget where finer resolution has been shown to pay off.

1. A harness gets coordinates

Every candidate is factorized as H = (s, θ), a structural skeleton and a token-level implementation, with the joint descriptor φ(H) = (φS(s); φT(θ)). The structural descriptor encodes the harness's component graph: top-level functions, classes and modules are vertices with deterministic role labels (perception, controller, memory, policy, …) and call, reference and import dependencies are edges. Two rounds of Weisfeiler–Lehman refinement hash each vertex's role-aware neighbourhood, and φS is the normalized histogram of those hashes, so renaming functions or splitting files leaves the coordinate unchanged while adding a perception module moves it. The token descriptor concatenates three standardized blocks, AST control-flow statistics, numeric constants and an embedding of the documentation text, each scaled by 1/√dim so that no block dominates distances. One k-means over the descriptors of a corpus of harness variants yields a Centroidal Voronoi Tessellation with k₀ cells (CVT-MAP-Elites); a candidate is placed by nearest centroid, which reads only its source and costs no evaluation.

2. Searching over the map

Standard CVT-MAP-Elites mutates blindly; standard harness-evolution loops (propose, evaluate, diagnose, refine) have no spatial coverage. Harness-MAP runs the LLM-guided loop across the archive. The five shaded operations in the paper's Algorithm 1 are each a headless, tool-using session over a candidate directory with its own skill specification:

meta-agentCoverage-gated initializationThe proposer is pointed at empty cells, with the centroid delta to an occupied cell verbalized as a structural or token-level direction, until ⌈m·k₀⌉ cells hold an evaluated founder (m = 50%).
mapSelect P cell elitesEach generation breeds from P = ⌈log₂ k₀⌉ elites, cycling through the occupied cells so that every region keeps getting mutation chances.
meta-agentDiagnoseA diagnostician reads the parent's code and episode traces end to end and names the binding constraint: a harness bug to fix, a model ceiling to scaffold, or a task gap that needs a goal-directed lever.
meta-agentDirective-steered variationEach of the C children gets a target in the map plus a design axis (spatial grounding, action planning, verification and recovery, efficiency, observation parsing), so siblings diverge by construction. The proposer makes one axis-distinct edit under a fixed harness skeleton.
meta-agentValidity filteringA child must keep the entry-point contract and pass an adversarial anti-cheat judge that rules on the mechanism in its code and traces, never on the score. A FAIL verdict removes it from selection.
mapEvaluate, archive, adaptThe child is scored on the search split, placed in its nearest cell, and kept if it is the cell's best. Then the map's resolution adapts.

The evaluation budget is counted explicitly, so every method in the paper is compared at the same number of candidate evaluations:

N = ⌈m·k₀⌉ + G · P · C

G generations, P parents per generation, C children per parent. Initialization is step T = 0 for every method; a Harness-MAP step spends P·C evaluations.

3. Adaptive resolution

A fixed grid wastes evaluations on uniform cells and lumps distinct candidates together in high-variance ones. At the end of each step, Harness-MAP picks the single occupied cell with the largest internal fitness range and sub-splits it with a local CVT. The sub-split is kept only if a child cell's elite beats the pre-split elite; otherwise it is reverted, and the parent cell logs its fitness distribution so it is not re-split until a new candidate changes it.

Centroids are fit on cached descriptors, so resolution adapts at zero evaluation cost: budget concentrates where finer cells have produced quality gains, while flat or saturated regions keep a coarse cell. In the paper's BALROG runs every major breakthrough came from a newly subdivided cell, and the archive grows incrementally rather than exponentially.

Results

Budget-matched comparison on three benchmarks

Every search method starts from the same reference harness and the same frozen policy model, Qwen3-VL-30B-A3B-Instruct served with vLLM, and gets the same number of candidate evaluations: N = 50 on SpatialWorld-3DGames and BALROG-MiniHack, N = 16 on SimWorld-MMNav. The meta-agent for the main results is claude-opus-5 through the Claude Code CLI; gpt-5.6-sol through the Codex CLI is used to check backbone robustness. Harness-MAP uses a 50% coverage-initialization ratio and sweeps the initial resolution k₀.

Sample efficiency in evaluations and in sequential steps

Under the budget-matched protocol the gains arrive early. On SpatialWorld-3DGames the k₀ = 4 run scores 71.0% at N = 10, above Meta-Harness's full-budget 68.6%, and reaches 100.0% by N = 40. On BALROG-MiniHack the k₀ = 2 run matches Meta-Harness's final 75.0% at N = 20, and k₀ = 16 reaches 90.0% at N = 50. Coverage-gated initialization alone frequently finds a saturating harness before the first search step, and the adaptive archive keeps improving across budget increments where the baselines plateau.

Resolution: sensitivity to k₀ and the adaptive mechanism

Cell count decides budget allocation. Too few cells reduce archive diversity; too many slow cell rotation and dilute the budget. Moderate initial resolutions win: k₀ ∈ {4, 8} reach 100.0% on the 3D games with every k₀ between 95.0% and 100.0%, and k₀ = 16 peaks at 90.0% on MiniHack, where k₀ = 32 drops to 40.0% under the same 50-evaluation budget. Across every k₀, the adaptive mechanism matches or beats the fixed and hierarchical variants on the 3D games: it refines the map incrementally, suppresses unhelpful sub-splits on simple landscapes such as Block3D, and deepens granularity on Maze3D and Rubik where quality gains are verified.

The map illuminates more of the space

To compare search methods with quality-diversity metrics, every candidate each method proposed on SpatialWorld-3DGames is embedded offline into the same structure-token descriptor space and mapped onto the k₀ Voronoi cells. As the grid gets finer, the baselines' local edits cover a collapsing fraction of cells, while Harness-MAP keeps coverage above 50% at every resolution and its QD-score keeps scaling.

The descriptor helps independently of the search loop

Crossing the two search loops with the two descriptors on SpatialWorld-3DGames (k₀ = 8) isolates the representation. OpenEvolve run over our structure-token CVT cells jumps from 21.9% to 71.4% and solves Maze and Block3D in 6 evaluations. Our loop run over OpenEvolve's two-dimensional complexity and diversity descriptor loses efficiency, 37 instead of 16 evaluations to solve Rubik, and fails to cover Maze3D.

The best MiniHack run (adaptive, k₀ = 16, 48 evaluations) evaluated 41 harnesses before reaching success 0.900 at evaluation 41. The path to the best is four harnesses long. Code

Run it on your own harness

The release at github.com/Harness-MAP/harness-evolution contains the method, the three benchmark configurations of the paper with their evolution packs, and the five baselines plus the two descriptor-swap ablations as budget-matched arms over pinned upstream clones. A benchmark plugs in through an anchor harness, an evaluator with a task split, a config file and an adapter; the search itself is never edited.

git clone https://github.com/Harness-MAP/harness-evolution.git
cd harness-evolution
pip install -e .                      # numpy, sentence-transformers, einops
python examples/toy/run_toy.py        # the method end to end on a toy task, no GPU, no LLM, ~10 s

# the paper's three benchmarks, after editing the placeholders in each run.sh
MODE=adaptive K0=4 bash examples/balrog/run.sh
GAME=maze3d_pro MODE=adaptive K0=8 bash examples/spatialworld_games/run.sh
SETTING=hard MODE=adaptive K0=4 bash examples/simworld_nav/run.sh

# a published baseline on the same anchor, evaluator and budget
python baselines/run_baseline.py --config examples/balrog/config.json \
    --anchor <ANCHOR_DIR> --baseline meta-harness --budget 50

harness_map/

  • qd/descriptors.py: roles, component graph, Weisfeiler–Lehman, AST / numeric / doc-text blocks
  • qd/partition.py: k-means, CVT fit, frozen φ, centroid ladder
  • qd/coverage.py, qd/archive.py, qd/modes.py: coverage-gated initialization, cells and breeding, the three resolution modes with budget accounting, ledger and resume
  • meta_agent/: proposer, judge and diagnostician skills over the Claude Code CLI, Codex CLI or any OpenAI-compatible chat API

examples/

  • run_benchmark.py: config + anchor + evaluator command → one search
  • balrog/, spatialworld_games/, simworld_nav/: the paper's configs, run scripts, setup notes and the evolution packs shown above
  • render/: episode logs → videos

baselines/

  • Meta-Harness, GEPA, DGM, OpenEvolve and ShinkaEvolve as arms over pinned clones
  • the two ablations: OpenEvolve over our CVT cells, and our loop over OpenEvolve's descriptor
  • one driver for every benchmark × arm pair, with the same anti-cheat gate and budget protocol
